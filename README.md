# Rome II Web Campaign Editor

Edit a running Total War: ROME II campaign from a web page.

用网页实时编辑正在进行的《全面战争：罗马2》战役。

Vibe coded: all of the project's own code was generated by AI. Inspired by IMRZ's [Web campaign editor](https://steamcommunity.com/sharedfiles/filedetails/?id=2295560801) for Total War: WARHAMMER II.

本项目是 vibe coding，代码全部由 AI 生成。灵感来自 IMRZ 为《全面战争：战锤2》做的 [Web campaign editor](https://steamcommunity.com/sharedfiles/filedetails/?id=2295560801)。

## How it works / 原理

```
Chrome / Edge  ── request.json ──►  %USERPROFILE%\rome2_web_editor_mod  ◄── Rome II (Lua, every 0.1 s)
Chrome / Edge  ◄── response.json ──┘
```

The page and the game exchange JSON files in one folder. The pack hooks into `lua_scripts/episodicscripting.lua`, the only game file it replaces.

网页和游戏通过同一个文件夹里的 JSON 文件交换数据。pack 挂在 `lua_scripts/episodicscripting.lua` 上，这是唯一被替换的游戏文件。

## Install / 安装

1. Press Win+R and run: `powershell.exe mkdir $env:USERPROFILE\rome2_web_editor_mod`
2. Subscribe on the Workshop, or copy `rome2_web_editor.pack` into `<Rome II>\data\`. Enable it and load a campaign.
3. Open https://thomastamht.github.io/rome2-campaign-editor/ in Chrome or Edge, click **Connect folder** and choose the folder from step 1.

1. 按 Win+R，运行：`powershell.exe mkdir $env:USERPROFILE\rome2_web_editor_mod`
2. 订阅创意工坊，或把 `rome2_web_editor.pack` 放进 `<罗马2>\data\`。启用后载入战役。
3. 用 Chrome 或 Edge 打开 https://thomastamht.github.io/rome2-campaign-editor/ ，点「连接文件夹」，选第 1 步的文件夹。

## Features / 功能

- View a live campaign map / 查看实时战略地图
- Create armies / 创建军队
- Add money to the treasury / 增加国库
- Change region owner / 更改地区归属
- Change public order / 修改地区治安
- Add population surplus / 增加人口盈余
- Trigger rebellions / 造成叛乱
- Repair buildings / 修复建筑
- Give experience to generals, agents and units / 增加将领、特工和士兵经验
- Change action points / 更改行动力
- Force war, peace, trade or vassalage / 强制宣战、和平、贸易或附庸
- Interface in English, 简体中文, 繁體中文 / 界面支持英文、简体中文、繁体中文

## DEI patch / DEI 补丁

`!rome2_web_editor_dei_patch.pack` adds DEI features to the editor. It replaces no game file; any load order.

- Unit list shows only DEI units
- Edit region population: nobles, citizens, poor, foreigners

`!rome2_web_editor_dei_patch.pack` 为编辑器加上 DEI 功能，不替换任何游戏文件，加载顺序无所谓。

- 兵种列表只显示 DEI 兵种
- 修改地区人口：贵族、公民、贫民、外邦人
